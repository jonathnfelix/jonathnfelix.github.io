University Projects

PsikisAI - Mental Health Text Insight

Made with Python, RoBERTa, PyTorch, Streamlit, LIME

A Streamlit app that uses a fine-tuned RoBERTa model to spot patterns across six mental health related categories in text. LIME explains why the model made its prediction, and it also supports batch analysis for multiple texts at once.

Smart Adaptive Traffic Light System

Made with Python, OpenCV, Streamlit, NumPy

A computer vision-based traffic monitoring system that detects and counts vehicles across predefined lanes using classical image processing, then adjusts traffic light duration based on vehicle density.

Laptop Price Estimator

Made with Python, Scikit-learn, XGBoost, Pandas, Streamlit

A machine learning regression system that estimates laptop prices based on hardware specifications. The project compares Linear Regression, Random Forest, and XGBoost before deploying the model through Streamlit.

SplitEase - Collaborative Split Bill Android App

Made with Kotlin, Jetpack Compose, Google Cloud Vision API

An Android application that uses Google Cloud Vision API to extract items and prices from receipts and helps users split bills collaboratively through shared sessions.
